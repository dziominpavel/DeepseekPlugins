# dsh-changes-fold

Карточка «Отредактированные файлы N» под ответом ассистента свёрнута до
заголовка; список файлов раскрывается кликом по строке «Показать файлы» и
сворачивается обратно.

- по умолчанию виден только заголовок карточки: иконка, «Отредактированные
  файлы N», `+добавлено −удалено`;
- под заголовком — строка-переключатель «Показать файлы» / «Свернуть» с
  шевроном;
- при раскрытии показываются все файлы, даже если их больше четырёх: плагин
  один раз нажимает штатную кнопку «Все файлы N», чтобы React отрисовал полный
  список;
- карточка с одним файлом не меняется — у неё и так нет списка;
- подписи переключателя переведены (en/ru) и меняются вместе с языком интерфейса.

## Как устроено

Карточку рисует `@deepseek-ai/dsh-client-ui-deliverables`; у неё нет конфига, а
слот `conversation.chat.turnTail` — list, поэтому запись нельзя перекрыть
приоритетом. Плагин не подменяет компонент и ничего не переносит в DOM:

1. добавляет стиль: у карточки `[data-changed-files]` без атрибута
   `data-dsh-fold-open` скрыт `ul` со списком и штатная кнопка «Все файлы N»;
2. между заголовком и списком вставляет свою строку-переключатель
   `[data-dsh-fold-toggle]`: она ставит/снимает атрибут карточки;
3. MutationObserver доставляет переключатель новым карточкам и восстанавливает
   его, если React перерисовал карточку.

Хостовая половина пустая: команда и настройки не нужны.

## Ограничения

- Привязка к разметке карточки (`data-changed-files`, `ul`, кнопка с
  `aria-expanded`). Если DSH изменит разметку, плагин просто перестанет
  сворачивать — чат не ломается, ошибки уходят в `console.warn`.
- Состояние раскрытия не запоминается: новые карточки и карточки,
  перерисованные React'ом, снова свёрнуты.
- Список файлов по-прежнему открывается в правой панели по клику на заголовок
  карточки или на строку файла.

## Установка

```text
plugin_manager install_bundle target=C:\projects\DeepseekPlugins\plugins\dsh-changes-fold
```

После установки обновить страницу DSH (клиентский модуль подхватывается новым
поколением).

# dsh-ru-locale — русский язык для веб-интерфейса DeepSeek Harness

Плагин-«языковой пакет» для DSH: добавляет в интерфейс язык `Русский` и подставляет
русские строки вместо встроенных английских. Работает через штатную службу локализации
(`@deepseek-ai/dsh-client-locale`), поэтому:

- переключение мгновенное, без перезагрузки страницы;
- выбранный язык сохраняется в настройках DSH и переживает перезапуск;
- непереведённые ключи автоматически падают на английский (никаких «сырых» ключей в UI);
- `<html lang>` выставляется в `ru`.

## Состав

| Файл | Назначение |
|---|---|
| `package.json` | манифест бандла: `dsh.bundle.patch` + клиентское расширение (`platform: web`) |
| `cordis.patch.yml` | вставляет строку плагина `ru-locale` в композицию профиля |
| `index.js` | хостовая половина — пустая, вся работа в браузере |
| `client.js` | собранный модуль: регистрация языка `ru` и словарей (58 пространств имён) |
| `translations/en/*.json`, `translations/ru/*.json` | исходники перевода по пространствам имён |
| `tools/build.mjs` | сборка `client.js` из `translations/` и проверка паритета ключей/плейсхолдеров |
| `locale/en.json`, `locale/ru.json` | название и описание плагина для списка плагинов |
| `icon.svg` | иконка плагина |

## Установка

```
plugin_manager install_bundle target=C:\projects\DeepseekPlugins\plugins\dsh-ru-locale
```

Установка выполняется в текущий профиль (`desktop`) и действует во всех сессиях профиля.
Если ссылка в профиле устарела после переезда каталога — `C:\projects\DeepseekPlugins\install.ps1 -Fix`.

## Как включить

Настройки → General → Language → **Русский**. Выбор записывается в настройки DSH.

## Как обновить перевод

1. Исходные английские строки лежат в `translations/en/<namespace>.json`
   (они сняты из клиентских пакетов DSH: `lib/client.js`, вызовы
   `ctx.locale.register(NS, { zh, en })`).
2. Правь `translations/ru/<namespace>.json`. Ключи и плейсхолдеры вида `{name}`
   менять нельзя — сборка это проверяет.
3. `node tools/build.mjs --write` — пересобрать `client.js` (без `--write` только
   проверка: пропущенные ключи, лишние ключи, расхождение плейсхолдеров).
4. Переустановить пакет в профиль (`plugin_manager install_bundle`) и перезапустить
   DSH: замена уже загруженного пакета требует нового поколения JS-модулей.

## Ограничения

- Покрыты пространства имён, которые DSH регистрирует через службу локализации.
  Строки, зашитые в код в обход службы, остаются английскими.
- Пакет живёт в общем каталоге плагинов DSH `C:\projects\DeepseekPlugins\plugins\dsh-ru-locale`,
  вне проектов: на сборку CarMusicMeter он не влияет. Профиль держит на каталог
  ссылку (junction), поэтому после перемещения нужна переустановка
  (`plugin_manager install_bundle`) или `C:\projects\DeepseekPlugins\install.ps1 -Fix`.

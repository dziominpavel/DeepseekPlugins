# Провайдер рядом с моделью

Плагин добавляет имя провайдера к названию модели в меню выбора модели
композера (`Модель` -> текущее значение). Полезно, когда один и тот же каталог
моделей отдают разные провайдеры (аккаунт DeepSeek и ключ API): по одной строке
видно, какой именно провайдер сейчас выбран.

```text
Модель   DeepSeek V4.1 Flash · DeepSeek     >
```

## Где появляется

| Место | Что показывает |
|---|---|
| Строка «Модель» в меню композера (`placement: menu`) | `Модель · Провайдер` |
| Кнопка композера (`placement: trigger`) | без изменений |
| Строки списка моделей (`placement: option`) | без изменений: они уже сгруппированы заголовками провайдеров |

Провайдер выводится приглушённым цветом (`--dsw-alias-label-secondary`), само
название модели не меняется. Строка меню остаётся одной строкой и обрезается
многоточием на узких экранах.

## Как устроено

Плагин занимает слот `conversation.input.model.label` — неинтерактивную
подпись модели, которую объявляет `@deepseek-ai/dsh-client-ui-model-selection`.
Правила выбора, поиск, клавиатура и доступность остаются у владельца слота:
компонент только рисует текст и не перехватывает клики. Хостовая половина
(`index.js`) пустая.

Слот `single`: встроенный `ui-deepseek-model-label-1017` уже занимает его на
приоритете 0, поэтому плагин регистрируется на приоритете `-1` — у `single`
рендерится запись с наименьшим приоритетом, а одинаковый приоритет был бы
ошибкой регистрации. Отключение плагина возвращает встроенный вид без
перезапуска приложения.

## Установка

```text
node --check client.js
plugin_manager install_bundle target=C:/projects/DeepseekPlugins/plugins/dsh-model-provider-label
```

Профиль один: установка идёт в текущий, при нескольких профилях (`desktop`,
`web`, `headless`) повторить для каждого.

## Ограничения

- Попап команды `/model` строит строки отдельным API и провайдера не показывает.
- Тултип и accessible name кнопки композера по-прежнему содержат только модель:
  это текст владельца слота, плагин на него не влияет.
- Провайдер берётся из каталога как есть: у провайдеров из `llm-pi-ai` это ключ
  конфигурации (`opencode-go`), пока в `providers.<key>.displayName` не задано
  имя. Аккаунт DeepSeek показывается как `DeepSeek Account`, ключ API — `DeepSeek`.

## Отключение

```yaml
- id: model-provider-label
  disabled: true
```

# dsh-sidebar-opencode

Список проектов и сессий в сайдбаре DSH, повторяющий привычки opencode:

- порядок сессий **только ручной**: новые падают в конец, перетаскивание мышью
  запоминается в `localStorage` (`dsh.opencode.order.v1`);
- у каждого проекта цветная буквенная иконка (цвет из хеша имени);
- работающая сессия — крутящийся индикатор, завершённая и непросмотренная —
  зелёная точка, ожидающая ответа — жёлтая;
- при завершении сессии играет короткий сигнал (включается/выключается кнопкой
  «звук» в шапке списка).

Установка:

```text
plugin_manager install_bundle target=C:\projects\DeepseekPlugins\plugins\dsh-sidebar-opencode
```

Плагин заменяет слот `sidebar.workspaces` и должен загружаться раньше
`@deepseek-ai/dsh-web-app` в `dsh.profile.bundles` — иначе останется штатный
браузер. Поиск, дерево workspace'ов, меню rename/archive/fork и hover-карточки
штатного браузера в этой версии не реализованы.

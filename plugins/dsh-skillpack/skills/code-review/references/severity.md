# Уровни находок

| Уровень | Когда ставить | Что значит для мержа |
|---|---|---|
| `блокер` | Потеря данных, падение, дыра в безопасности, сломанный контракт для существующих вызовов | Мержить нельзя |
| `важно` | Ошибка в редком пути, утечка ресурса, отсутствие проверки внешнего ввода | Мержить можно после правки |
| `мелочь` | Читаемость, мёртвый код, неточное имя, лишний лог | Мержить можно, чинить по случаю |

Правила:

- Уровень — про последствие, а не про размер правки. Одна строка может быть блокером, сто строк — мелочью.
- Сомневаешься между двумя уровнями — ставь меньший и объясни, чего не хватает, чтобы поднять.
- Находка без последствия — не находка: если не можешь сказать, что сломается, не пиши её.

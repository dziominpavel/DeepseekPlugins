# dsh-session-purge

Безвозвратное удаление **архивных** сессий DSH — у штатного харнесса удаления
сессий нет, они только архивируются, и список со временем разрастается.

Плагин даёт два входа:

- **HTTP-маршрут `POST /api/session.purge`** — его вызывает корзина в архиве
  сайдбара `dsh-sidebar-opencode`. Открытая сессия не нужна: запрос идёт через
  `/api`-мост Connection и аутентифицируется cookie страницы. Тело:
  `{ "sessionId": "session-<uuid>" }`, ответ — JSON `{ ok: true, … }`.
- **Глобальная команда** для ручного вызова и композиций без Connection:

  ```text
  /delete-archived session-<uuid>
  /delete-archived --check session-<uuid>   # только проверить, ничего не удаляя
  ```

Оба входа проверяют, что сессия архивная и не загружена в память, затем удаляют:

- каталог журнала `~/.dsh/sessions/<проект>/<session-id>/` (у обычных сессий
  каталог назван полным id, у старых записей и субагентских — голым uuid;
  команда ищет оба варианта, а точный путь сначала берёт из
  `sessionPersistence.stat()`);
- кэш проекций: запись `session_projcache` через открытый storage-домен и
  legacy-файлы `~/.dsh/storages/session_projcache/sessions/<id>.json`;
- запись в реестре: убирает id из архива и из всех проектов, где он числится.

Индекс полнотекстового поиска (SQLite FTS) чистится сам при следующем поиске:
он сверяется с журналами и выкидывает исчезнувшие сессии.

## Откуда вызывается

- Из сайдбара `dsh-sidebar-opencode` 0.10.2+: у архивной строки есть корзина
  «Удалить навсегда» с подтверждением. Строка пропадает сразу, без открытия
  другой сессии и без служебной строки в чьём-либо журнале.
- Вручную из композера: `/delete-archived session-…`.

## Ограничения

- Только архивные сессии: живую сессию плагин не тронет.
- Если сессия ещё висит в памяти процесса, удаление попросит перезапустить DSH.
- Вложения сессии не удаляются: они общие для профиля и адресуются по хешу.
- Отменить удаление нельзя.

## Проверка

```powershell
node tools/test-session-purge.mjs       # временный DSH_HOME: удаление, кэш, реестр, HTTP-маршрут
node tools/smoke-sidebar-opencode.mjs   # корзина в сайдбаре вызывает удаление без открытой сессии
```

## Установка

```text
plugin_manager install_bundle target=C:/projects/DeepseekPlugins/plugins/dsh-session-purge
```

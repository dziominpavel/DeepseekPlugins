# dsh-session-purge

Безвозвратное удаление **архивных** сессий DSH — у штатного харнесса удаления
сессий нет, они только архивируются, и список со временем разрастается.

Плагин регистрирует глобальную команду:

```text
/delete-archived session-<uuid>
/delete-archived --check session-<uuid>   # только проверить, ничего не удаляя
```

Команда проверяет, что сессия архивная и не загружена в память, затем удаляет:

- каталог журнала `~/.dsh/sessions/<проект>/<session-id>/` (у обычных сессий
  каталог назван полным id, у старых записей и субагентских — голым uuid;
  команда ищет оба варианта);
- кэш проекций `~/.dsh/storages/session_projcache/sessions/session-<uuid>.json`;
- запись в реестре: убирает id из архива и из списка сессии проекта.

Индекс полнотекстового поиска (SQLite FTS) чистится сам при следующем поиске:
он сверяется с журналами и выкидывает исчезнувшие сессии.

## Откуда вызывается

- Из сайдбара `dsh-sidebar-opencode` v0.9.13: у архивной строки появляется
  корзина «Удалить навсегда» с подтверждением.
- Вручную из композера: `/delete-archived session-…`.

Команда выполняется в контексте открытой сессии, поэтому каждый вызов оставляет
в её журнале служебную строку команды (так устроен канал команд DSH).

## Ограничения

- Только архивные сессии: живую сессию команда не тронет.
- Если сессия ещё висит в памяти процесса, команда попросит перезапустить DSH.
- Вложения сессии не удаляются: они общие для профиля и адресуются по хешу.
- Отменить удаление нельзя.

## Установка

```text
plugin_manager install_bundle target=C:/projects/DeepseekPlugins/plugins/dsh-session-purge
```

# Proposal

## Why

DSH не имеет управляемой памяти между сессиями. Стабильные предпочтения и
договорённости живут либо в `AGENTS.md` (это инструкции, а не данные), либо в
истории сессий, которую агент не обязан просматривать. В результате агент
повторно выясняет одно и то же, а накопленный контекст нельзя перенести между
агентами, профилями и машинами.

Hermes Agent показывает, что проблема решается не «большим файлом», а маленьким
always-on слоем фактов, автономной записью и поиском по истории. В DSH уже есть
skills, сессии и prompt-caching, но нет самого слоя памяти.

## What Changes

- Новый self-contained host-плагин `@local/dsh-memory` по образцу
  `dsh-skillpack`: файлы `MEMORY.md` и `USER.md` в `~/.dsh/memory`, tool
  `memory` (`add` / `replace` / `remove` / `list`) с записью **без
  подтверждения**.
- Frozen-инъекция памяти в системный промпт на сессию: записи в текущей сессии
  видны в ответах tool'а, в промпт попадают со следующей сессии; prefix-кэш не
  ломается.
- Guardrails вместо approval: лимиты, дедупликация, атомарная запись с
  блокировкой, скан prompt injection/секретов/невидимых символов; опасная
  запись отклоняется с понятной ошибкой.
- Аудит и обратимость: `audit.jsonl` + история версий,
  `/memory list|show|log|undo|export|import`.
- Навык `skills/memory/SKILL.md` внутри пакета: что сохранять, как курировать,
  чего не сохранять; регистрируется через `ctx.skills.register`.
- Переносимость: установка через `plugin_manager install_bundle`, снимок
  профиля через `install.ps1 -Capture` / `-Restore`; данные — через
  `/memory export|import` (не внутри пакета).
- **BREAKING**: нет — новый плагин, существующие плагины и их контракты не
  меняются.

### Вне scope

- `dsh-skill-manager` (самоулучшение скиллов) — отдельный change.
- Официальный `@deepseek-ai/dsh-experimental-session-search` — включается
  отдельно, не входит в пакет.
- Внешние memory-провайдеры (Honcho/mem0 и т.п.).
- UI-настройки памяти; в v1 — команда `/memory`.

## Capabilities

### New Capabilities

- `agent-memory`: управляемая durable-память агента — автономная запись фактов и
  предпочтений, frozen-инъекция в промпт, лимиты/скан/аудит, перенос данных.

### Modified Capabilities

Нет.

## Impact

- Новый пакет `plugins/dsh-memory/**` (host-половина, `skills/memory`, locale,
  icon, README).
- `README.md`, `docs/PLUGINS-GUIDE.md`, `AGENTS.md` — строка нового плагина.
- `profile/desktop/` — снимок после установки (`install.ps1 -Capture`).
- Данные пользователя: `~/.dsh/memory/**` (вне репозитория, переносятся
  export/import).
- Существующие плагины, профили и сессии не меняются.

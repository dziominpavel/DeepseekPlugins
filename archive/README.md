# archive — снятые плагины

Каталоги здесь не устанавливаются: `install.ps1` и `plugin_manager` смотрят только
в `plugins/`. Лежат для истории и на случай отката.

## dsh-ru-locale

Русский интерфейс для DSH. Снят 05.11.2026, потому что в DSH 0.2.2 (0.2.2-rc.1)
русский язык уже входит в базовую поставку: клиентская служба локализации
регистрирует восемь языков (`zh`, `en`, `ja`, `es`, `fr`, `de`, `ru`, `pt`),
словари `ru` лежат более чем в 60 клиентских пакетах, а выбрать язык можно в
**Настройки → Общие → Язык → Русский**.

Оставлять плагин включённым нельзя: он вызывает
`ctx.locale.addLanguage({ id: 'ru', ... })`, а база уже зарегистрировала `ru`,
поэтому служба бросает `locale "ru" is already registered` — клиентская половина
плагина не запускается. Даже если бы язык удалось добавить, `locale.register(ns, 'ru', dict)`
для тех же пространств имён тоже падает на дубликате.

Плюс перевод плагина снят со старой версии клиента: его ключи расходятся с
актуальными, а базовый перевод свежий.

Вернуть, если понадобится: перенести каталог обратно в `plugins/`, убрать
`addLanguage`/`register` для уже существующих языков и переустановить.

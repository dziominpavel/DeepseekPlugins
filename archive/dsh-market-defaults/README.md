# dsh-market-defaults

Конфигурационный bundle: заранее добавляет источники индексов в официальный
экспериментальный маркет DSH. Своих строк и кода не содержит — только патч
`plugin-market`.

## Что делает

Прописывает в `plugin-market` два публичных индекса:

- `https://cdn.jsdelivr.net/npm/dsh-plugin-catalog/index.json` — каталог
  awesome-dsh-plugin (через jsDelivr, быстро отдаётся);
- `https://dshopen.org/index.json` — открытый индекс сообщества.

После установки в **Плагины → Откройте для себя** сразу видны плагины, без
ручного поиска ссылок.

## Требования и порядок

Нужен включённый официальный бандл
`@deepseek-ai/dsh-experimental-plugin-market-bundle`: этот патч правит его
строку `plugin-market`. В `dsh.profile.bundles` этот бандл должен стоять
**после** маркета — `plugin_manager install_bundle` дописывает его в конец, так
что при обычной установке порядок правильный.

## Настройка

Пользовательские источники меняются в Discover как обычно. Настройки профиля
(`cordis.patch.yml`) применяются позже и целиком заменяют конфиг из этого
бандла, поэтому выбор пользователя всегда главнее.

Список индексов меняется в `cordis.patch.yml` этого пакета.

## Доверие

Оба индекса — сторонние, не официальный каталог DeepSeek. Плагины оттуда
ставятся как обычные npm/git-пакеты и выполняют код; ставьте только то, чей
источник вы проверили.
